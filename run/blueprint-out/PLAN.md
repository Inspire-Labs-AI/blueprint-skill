> Generated by the `blueprint` skill, Phase 1 (recon + plan). Evidence-led: every
> claim tagged **[observed]** (seen in browser/network) or **[inferred]** (reasoned).
> Target: https://www.mprofit.in/ · Date: 2026-08-24

## 1. Overview
MProfit is an Indian multi-asset **portfolio tracking + investment-accounting** product
for two audiences: investors/HNIs/family offices, and wealth professionals (RIAs, CAs).
Core value: auto-import trades from 700+ brokers into a tax-aware ledger (XIRR,
ITR-format capital gains). **[observed: marketing site]**

## 2. Architecture reality (the key finding)
- The **public site is Gatsby SSG** — no runtime backend. All content is baked into
  `/page-data/*.json` at build (index page-data = 42 KB incl. pricing text). **[observed]**
- Analytics only on the wire: Google GTM/GA4, Microsoft Clarity, DoubleClick. **[observed]**
- `api.mprofit.in` root not reachable from the browser. **[observed]**
- The **real product ("MProfit Cloud") is a separate authenticated SPA** — its API was
  NOT captured (login required). Everything about it below is **[inferred]** until an
  authorized login-capture is run. **[observed: /login exists; separate app]**

> ⚠️ MOM claim "pricing calculator API is publicly accessible" was NOT reproduced on
> the public marketing site. It is likely behind login or on the app subdomain — must be

## 9. Effort & cost estimate  ← headline
| Layer | Complexity | Notes |
|---|---|---|
| Marketing site clone | **S** | Gatsby SSG, static — 1–2 days |
| Product frontend (dashboard/holdings/reports) | **L** | many stateful screens |
| Backend + API (import engine, 700+ broker parsers, XIRR, ITR capital-gains) | **XL** | the real moat; broker parsers alone are huge |
| Auth + multi-tenant + compliance | **L** | financial-grade |

- **Marketing-shell clone:** ~2–3 days (realistic).
- **Functional product clone (authorized capture → real API + FE + BE):** **~4–8 weeks**
  for a small team — the 700+ broker import parsers and tax engine dominate.
- **Token/$ to auto-generate with agents:** rough **$3k–$8k** for FE + API scaffolding
  from captured data; the broker parsers & tax logic are NOT cheaply agent-generatable.
- **1-week kill-switch verdict:** a *marketing + dashboard shell* is achievable in a week;
  a *functional* End Profit clone is **not** — it fails the 1-week test. Recommend: scope
  the week to "authorized capture + real API map + FE shell + coverage report," then decide.

## 10. Risks & gaps
- **Biggest:** the entire product is behind login and was not captured → all backend
  claims are inferred. **Next action: authorized login + network capture** to convert
  §5/§6 from inferred to observed. That single step is the difference between a demo shell
  and a real clone.
- Broker-import parsers (700+) and the ITR tax engine are the real cost centers and are
  not visible from any crawl.
